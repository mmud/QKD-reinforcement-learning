# QKD Eavesdropping Research Code

`main.ipynb` is the restored value-targeted simulator and RL experiment notebook. It is the project baseline for incremental, reviewable changes.

- `main_value_targeted_legacy.ipynb` preserves the earlier edited draft.
- `prototypes/threat_aware_initial/` preserves the separate availability-attack prototype developed from the new project direction.
- Generated models, result tables, and figures are excluded from Git.

Start with `requirements.txt`, then run `main.ipynb` from top to bottom. The notebook includes long PPO training sections; use its quick-test configuration before full runs.
